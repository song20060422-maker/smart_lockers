# 工单08 Go后端性能调优工具链 — 接口与使用文档
> **工单编号：08｜Go后端性能调优工具链**　需求来源：智能快寄柜 10 份任务工单 V1.x　创建人：邹世军　出品：八维文化与产业研究院（内容由 AI 生成，仅供参考）

## 1. 接口清单
全部接口需鉴权；非 debug 模式仅内网可访问（guard 中间件），否则返回 10003 禁止访问。

| 接口 | 用途 |
|---|---|
| GET /api/v1/ops/pprof/ | pprof 索引页 |
| GET /api/v1/ops/pprof/profile?seconds=30 | CPU 采样 |
| GET /api/v1/ops/pprof/heap | 堆内存剖面 |
| GET /api/v1/ops/pprof/goroutine?debug=2 | 协程栈 |
| GET /api/v1/ops/pprof/block | 锁竞争 |
| GET /api/v1/ops/trace?seconds=5 | 执行 trace |
| GET /api/v1/ops/expvar | runtime/metrics 指标 |

## 2. 使用示例
```bash
# 采集 CPU 剖面并生成火焰图
curl -o cpu.pprof "http://127.0.0.1:18080/api/v1/ops/pprof/profile?seconds=30"
go tool pprof -http=:0 cpu.pprof
# 采集 trace
curl -o trace.out "http://127.0.0.1:18080/api/v1/ops/trace?seconds=5"
go tool trace trace.out
# 查看指标
curl "http://127.0.0.1:18080/api/v1/ops/expvar"
```
## 3. 使用注意
- 生产默认不暴露公网；分析完成后关闭采样，控制开销 < 3%。
- 采样会影响性能，避开业务高峰；profile 默认 30s、trace 建议 ≤5s。
- 结合 04 面板长期监控、03 火焰图/trace 做深度定位。
