# 工单02 快寄员支付宝支付 — 接口报文设计说明书

> **工单编号：02｜快寄员支付宝支付**　需求来源：智能快寄柜 10 份任务工单 V1.x　创建人：邹世军　出品：八维文化与产业研究院（内容由 AI 生成，仅供参考）

## 1. 通用报文约束
- 全部接口 HTTP 状态码恒定 200，业务结果由 body 中 `code` 判定（0 成功）。
- 统一响应结构（`@ticket 00-project`）：`{"code":0,"message":"ok","data":{},"request_id":"..."}`。
- 除 `/auth/login` 与回调外，业务接口均需 `Authorization` 令牌（middleware.Auth）。
- 写接口支持幂等键 `Idempotency-Key` 或 query `idempotency_key`。
- 错误码采用统一错误码表（见下），禁止自定义散落格式。

## 3. GET /api/v1/pay/balance — 查询余额
- 鉴权：Bearer 令牌

**响应示例**
```json
{"code":0,"message":"ok","data":{"balance":12000}}
```

## 4. GET /api/v1/pay/balance/logs — 余额明细
- 鉴权：Bearer 令牌

**请求参数**
| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| page | int | 否 | 页码，默认1 |
| page_size | int | 否 | 每页，默认20 |

**响应示例**
```json
{"code":0,"data":{"list":[{"change_amount":500,"balance_after":12000,"biz_type":"recharge"}],"total":12}}
```

## 5. POST /api/v1/pay/recharge — 创建充值单
- 鉴权：Bearer 令牌

**请求参数**
| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| amount | int64 | 是 | 充值金额，>0（分） |

**响应示例**
```json
{"code":0,"data":{"charge_no":"C20260101001","amount":500}}
```

**业务错误**：12003 回调校验失败

## 6. GET /api/v1/pay/recharge/records — 充值记录
- 鉴权：Bearer 令牌

**请求参数**
| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| page | int | 否 | 页码 |
| page_size | int | 否 | 每页 |

**响应示例**
```json
{"code":0,"data":{"list":[{"charge_no":"C...","status":2,"amount":500}]}}
```

## 7. POST /api/v1/pay/alipay/callback — 回调幂等入账
- 鉴权：支付宝签名校验（非用户令牌）

**请求参数**
| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| charge_no | string | 是 | 充值单号 |
| trade_no | string | 是 | 支付宝交易号 |
| amount | int64 | 是 | 金额>0 |
| signature | string | 否 | 签名 |

**响应示例**
```json
{"code":0,"data":{"credited":true,"balance":12500}}
```

**业务错误**：12002 充值单不存在；12003 校验失败；10007 重复请求
