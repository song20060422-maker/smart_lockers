## 1. 需求概述
实现快寄员支付宝支付：余额查询、余额流水、充值下单、支付宝回调幂等入账、支付校验，支撑寄存下单与超时补缴的资金流转。工时约3人日。

## 2. 设计目标与约束
资金安全为首要目标：金额以分为单位的整型、DB 余额为准、回调签名校验、幂等入账、事务一致。遵循全局铁律（@ticket 注释、单测≥70%、统一错误码/日志、压测报告、事务/幂等/鉴权/脱敏/审计、可配置）。

## 3. 总体架构
```
Handler(pay.go) → Service(account/recharge) → Model(account/balance_log/recharge_order)
  ├─ 读：balance / balance/logs / recharge/records
  └─ 写：recharge 下单 → 支付宝 → callback 回调验签+幂等入账
```
余额查询与流水：从 account / balance_log 读取，balance 以 DB 为准。
充值下单：CreateRecharge 生成 charge_no，状态置待支付，拉起支付宝。
回调入账：RechargeCallback 校验 charge_no/trade_no/amount/signature，幂等键去重，事务内更新订单状态+账户余额+写流水。
资金一致：入账事务失败整体回滚，重复回调按幂等返回成功或 ErrDup。

## 4. 核心流程
1. 余额查询与流水：从 account / balance_log 读取，balance 以 DB 为准。
2. 充值下单：CreateRecharge 生成 charge_no，状态置待支付，拉起支付宝。
3. 回调入账：RechargeCallback 校验 charge_no/trade_no/amount/signature，幂等键去重，事务内更新订单状态+账户余额+写流水。
4. 资金一致：入账事务失败整体回滚，重复回调按幂等返回成功或 ErrDup。
