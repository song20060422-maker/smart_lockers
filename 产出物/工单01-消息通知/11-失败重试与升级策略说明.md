# 工单01 消息通知与告警中心 — 失败重试与升级策略说明

> **工单编号：01｜消息通知**　需求来源：智能快寄柜 10 份任务工单 V1.x　创建人：邹世军　出品：八维文化与产业研究院（内容由 AI 生成，仅供参考）

## 1. 失败分类
| 类型 | 示例 | 是否重试 |
|---|---|---|
| 可重试 | 渠道超时、网络抖动、限流 | 是 |
| 不可重试 | 模板不存在、参数错误、接收方无效 | 否 |

## 2. 重试策略
- **退避算法**：指数退避，第 n 次重试间隔 = base × 2^(n-1)，base 默认 1s，加随机抖动防雪崩。
- **最大次数**：默认 3 次（可配置），每次重试 `retry_count++`，状态置 3（重试中）。
- **重试上限后**：状态置 2（失败），进入升级流程。

## 3. 升级策略
- 一级：失败后自动重试（原渠道）。
- 二级：重试耗尽后，升级到备用渠道（如 inbox 失败升级 sms）。
- 三级：关键场景（SYSTEM_ALERT）失败后升级通知平台管理员（admin），并写审计。

## 4. 状态流转
```
待发(0) → 失败(2) → 重试中(3) → 成功(1) 或 失败(2) → 升级渠道重投
```

## 5. 补偿机制
- 定时扫描 `status IN (0,2,3)` 且 `created_at` 超窗口的记录，触发补偿重投。
- 补偿同样受去重与频控约束，避免重复轰炸。
