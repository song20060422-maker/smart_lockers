# 工单01 消息通知与告警中心 — 审计与回执报表

> **工单编号：01｜消息通知**　需求来源：智能快寄柜 10 份任务工单 V1.x　创建人：邹世军　出品：八维文化与产业研究院（内容由 AI 生成，仅供参考）

## 1. 审计要素
| 字段 | 说明 |
|---|---|
| message_id | 通知消息ID |
| tpl_code / scene | 模板/场景 |
| receiver_type / receiver_id | 接收方 |
| channel | 渠道 |
| action | 触发/投递/重试/升级/去重拒绝 |
| result | 成功/失败/拒绝 |
| operator | 系统/触发方 |
| timestamp | 时间戳 |
| request_id | 链路追踪ID |

## 2. 审计记录时机
- 触发通知、投递成功/失败、每次重试、升级、去重/频控拒绝，均写审计日志。
- 审计日志与 `notify_message` 状态变更一一对应，可追溯。

## 3. 回执报表
- **渠道回执**：渠道 ack 结果写回 status，失败写失败原因。
- **日报/周报**：按场景/渠道统计投递量、成功率、平均时延、失败TOP原因。
- **对账**：按 receiver 汇总投递记录，供业务方核对。

## 5. 安全与留存
审计报表含 receiver_id 等标识，按脱敏规则展示；审计日志按合规要求留存，不做物理删除。
