# 工单01 消息通知与告警中心 — 接口报文设计说明书

> **工单编号：01｜消息通知**　需求来源：智能快寄柜 10 份任务工单 V1.x　创建人：邹世军　出品：八维文化与产业研究院（内容由 AI 生成，仅供参考）

## 1. 通用报文约束
- 全部接口 HTTP 状态码恒定 200，业务结果由 body 中 `code` 判定（0 成功）。
- 统一响应结构（`@ticket 00-project`）：`{"code":0,"message":"ok","data":{},"request_id":"..."}`。
- 鉴权：除 `/auth/login` 外，通知类接口均需 `Authorization` 令牌（middleware.Auth）。
- 错误码采用统一错误码表，本模块相关：10001 参数错误、10002 登录失效、10006 频控、10007 重复请求、16001 模板不存在。

## 2. POST /api/v1/notify/send — 发送通知
**请求**（来源：`internal/handler/notify.go`）
| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| tpl_code | string | 是 | 模板编码 |
| receiver_type | string | 是 | admin/site_admin/user |
| receiver_id | uint | 是 | 接收方ID |
| channel | string | 否 | 渠道，覆盖模板默认 |
| vars | map[string]string | 否 | 模板变量 |
| dedupe_key | string | 否 | 自定义去重键 |

请求示例：`{"tpl_code":"ORDER_CREATED","receiver_type":"user","receiver_id":12,"channel":"inbox","vars":{"order_no":"D20260101001"}}`
**响应**：`{"code":0,"message":"ok","data":{"message_id":88,"status":0},"request_id":"..."}`
**错误**：16001 模板不存在；10006 频控命中；10007 去重命中。
