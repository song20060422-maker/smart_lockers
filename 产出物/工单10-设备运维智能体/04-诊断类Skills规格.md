# 工单10 设备运维智能体 — 诊断类 Skills 规格（05-08）
> **工单编号：10｜设备运维智能体**　需求来源：智能快寄柜 10 份任务工单 V1.x　创建人：邹世军　出品：八维文化与产业研究院（内容由 AI 生成，仅供参考）

诊断类 Skills 基于上下文做根因/关联/健康/变更影响分析，输出遵循统一结构（见 01）。

## Skill 05 alert-attribution（告警归因）
- 输入：告警事件、时间窗口。
- 方法：关联同期指标/日志/变更，按因果强度排序候选根因。
- 输出：根因列表 + 置信度 + 依据。

## Skill 06 correlation（关联分析）
- 输入：多个事件/指标序列。
- 方法：时间相关性 + 拓扑依赖，识别共因与连锁故障。

## Skill 07 health-check（健康检查）
- 输入：设备/服务范围。
- 输出：健康评分与异常项清单，风险分级。

## Skill 08 change-impact（变更影响评估）
- 输入：变更单（版本/配置/发布）。
- 输出：受影响设备/服务清单 + 风险等级 + 回退建议。

## 输出示例
```markdown
## 运维分析结论
- **问题类型**：告警
- **风险等级**：高（多台设备同时离线）
- **运维背景**：站点 S1 设备 A01/A02 10:05 同时离线
- **下一步动作**：排查站点网络/交换机；暂不执行重启
- **执行记录摘要**：alert-attribution(指向网络) + correlation(同站点共因) + health-check
```
