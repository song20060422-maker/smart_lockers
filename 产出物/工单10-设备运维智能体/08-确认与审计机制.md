# 工单10 设备运维智能体 — 确认与审计机制
> **工单编号：10｜设备运维智能体**　需求来源：智能快寄柜 10 份任务工单 V1.x　创建人：邹世军　出品：八维文化与产业研究院（内容由 AI 生成，仅供参考）

## 1. 设计（audit/confirmation-and-audit.md）
风险动作（restart/isolate/rollback）执行必须满足"**先确认、后执行、全留痕**"。

## 2. 确认流程
1. Skill 命中风险动作 → 输出动作占位 + 影响面 + 回退方式。
2. 状态置 **待确认**，无确认不得调用执行接口。
3. 操作人确认（含依据）→ 状态转"已确认"→ 执行。
4. 执行结果回写审计日志。

## 3. 审计要素
| 字段 | 说明 |
|---|---|
| 操作人 | 确认人身份 |
| 时间 | 确认/执行时间戳 |
| 动作 | Skill 名 + 目标 + 参数 |
| 依据 | 关联分析结论/工单号 |
| 结果 | 执行结果/回退情况 |

## 4. 合规
- 审计日志只追加、不可篡改；敏感信息脱敏。
- 与统一输出结构的"高风险动作"段联动，保证结论可追溯。
