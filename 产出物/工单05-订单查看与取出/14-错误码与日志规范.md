# 工单05 订单查看与取出 — 错误码与日志规范
> **工单编号：05｜订单查看与取出**　需求来源：智能快寄柜 10 份任务工单 V1.x　创建人：邹世军　出品：八维文化与产业研究院（内容由 AI 生成，仅供参考）

## 1. 业务错误码
| 码 | 含义 |
|---|---|
| 14001 | 开柜授权无效 |
| 14002 | 令牌已过期或用尽 |
| 14003 | 订单不存在 |
| 14004 | 当前状态不允许该操作 |
| 10007 | 重复请求（幂等） |
## 2. 日志规范
- request_id 贯穿；写动作记录 order_no、user_id、动作、结果。
- 令牌、手机号脱敏；状态不允许、令牌失效记 WARN。
- 错误码与 HTTP 状态解耦（HTTP 200 + 业务码），响应含 request_id。
