# 工单05 订单查看与取出 — 接口报文设计说明书

> **工单编号：05｜订单查看与取出**　需求来源：智能快寄柜 10 份任务工单 V1.x　创建人：邹世军　出品：八维文化与产业研究院（内容由 AI 生成，仅供参考）

## 1. 通用报文约束
- 全部接口 HTTP 状态码恒定 200，业务结果由 body 中 `code` 判定（0 成功）。
- 统一响应结构（`@ticket 00-project`）：`{"code":0,"message":"ok","data":{},"request_id":"..."}`。
- 除 `/auth/login` 与回调外，业务接口均需 `Authorization` 令牌（middleware.Auth）。
- 写接口支持幂等键 `Idempotency-Key` 或 query `idempotency_key`。
- 错误码采用统一错误码表（见下），禁止自定义散落格式。
## 2. 全局错误码表

|---|---|

| 10001 | 参数错误 |

## 3. GET /api/v1/orders — 订单列表
- 鉴权：Bearer 令牌

**请求参数**
| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| status | int | 否 | 状态筛选 |
| page | int | 否 | 页码 |
| page_size | int | 否 | 每页 |

**响应示例**
```json
{"code":0,"data":{"list":[{"order_no":"D...","status":1,"amount":350}],"total":8}}
```

## 5. GET /api/v1/orders/:order_no — 订单详情
