# 工单05 订单查看与取出 — 监控指标面板与报警规则
> **工单编号：05｜订单查看与取出**　需求来源：智能快寄柜 10 份任务工单 V1.x　创建人：邹世军　出品：八维文化与产业研究院（内容由 AI 生成，仅供参考）

## 1. 指标面板
| 指标 | 说明 | 报警阈值 |
|---|---|---|
| orders QPS / P95 | 订单接口吞吐/时延 | P95>500ms |
| open_auth_fail_rate | 开柜失败率 | >10% |
| makeup_success_rate | 补缴成功率 | <95% |
| state_conflict_rate | 状态冲突(14004)率 | 突增告警 |
| db_error_rate | DB 错误率 | >1% |
## 2. 报警规则
- 连续 5 分钟 P95 超阈值 → 告警。
- 开柜失败率/状态冲突突增 → 立即告警（影响取件）。
- 补缴成功率下跌 → 告警（影响资金）。
## 3. 大盘
Prometheus 采集 + Grafana 面板，按接口/错误码维度聚合，支持按工单(05)筛选。
