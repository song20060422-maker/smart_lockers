# 工单05 订单查看与取出 — 设计说明书

> **工单编号：05｜订单查看与取出**　需求来源：智能快寄柜 10 份任务工单 V1.x　创建人：邹世军　出品：八维文化与产业研究院（内容由 AI 生成，仅供参考）

## 1. 需求概述
实现订单查看与取出服务：订单列表/历史/详情、进行中聚合、临时开柜授权与令牌使用、超时补缴、完成订单，支撑用户查询与取件全流程。工时约4人日。

## 2. 设计目标与约束
核心是订单状态机与资金/柜门一致：状态约束可执行动作、临时令牌限次防重放、补缴/完成幂等。遵循全局铁律（@ticket 注释、单测≥70%、统一错误码/日志、压测报告、事务/幂等/鉴权/脱敏/审计、可配置）。

## 3. 总体架构
```
Handler(order.go) → Service(order) → Model(deposit_order/temp_open_auth/makeup_record)
  ├─ 查询：list / summary/ongoing / detail
  └─ 动作：open-auth / use / makeup / complete（均受状态机约束）
```
OrderList / OngoingSummary / OrderDetail：按 user_id 查询，详情附带 actions 可执行动作清单。
CreateOpenAuth / UseOpenAuth：限次令牌，校验 expire_at 与 used_times，防重放。
MakeupPayment：幂等补缴，写 makeup_record。
CompleteOrder：状态从进行中→已完成，释放柜门、结算押金。

## 4. 核心流程
1. OrderList / OngoingSummary / OrderDetail：按 user_id 查询，详情附带 actions 可执行动作清单。
2. CreateOpenAuth / UseOpenAuth：限次令牌，校验 expire_at 与 used_times，防重放。
3. MakeupPayment：幂等补缴，写 makeup_record。
4. CompleteOrder：状态从进行中→已完成，释放柜门、结算押金。
