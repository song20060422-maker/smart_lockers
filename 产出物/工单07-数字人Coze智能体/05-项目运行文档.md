# 工单07 数字人Coze智能体 — 项目运行文档（环境搭建/配置步骤/测试用例）
> **工单编号：07｜数字人Coze智能体**　需求来源：智能快寄柜 10 份任务工单 V1.x　创建人：邹世军　出品：八维文化与产业研究院（内容由 AI 生成，仅供参考）

## 1. 环境搭建
- Node.js ≥ 18；npm/pnpm；现代浏览器（支持 WebSocket / Web Speech API）。
- 进入 `digital_human/`，`npm install` 安装依赖；`npm run dev` 启动（默认 5174 端口）。
- Coze 智能体：按 01 配置在 Coze 平台创建 bot，导入插件/工作流/知识库。
- Live2D 模型：将授权模型（haru/shizuku）放入 `public/models/`，见 `public/models/README.md`。

## 2. 配置步骤（环境变量 .env）
| 变量 | 说明 | 示例 |
|---|---|---|
| VITE_COZE_API_BASE | Coze API 地址 | /coze/v1 |
| VITE_COZE_BOT_ID | 智能体ID | <bot_id> |
| VITE_COZE_TOKEN | 访问令牌 | <token> |
| VITE_WS_URL | WebSocket 地址 | /ws/digital-human |
| VITE_TTS_PROVIDER | TTS 提供方 | web-speech/azure/openai |
| VITE_LIVE2D_MODEL_PATH | 模型路径 | /models/haru/haru.model3.json |
