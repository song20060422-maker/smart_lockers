# 工单04 物品寄存 — 柜子信息接口文档

> **工单编号：04｜物品寄存**　需求来源：智能快寄柜 10 份任务工单 V1.x　创建人：邹世军　出品：八维文化与产业研究院（内容由 AI 生成，仅供参考）

## 1. 接口概述
- **地址**：`GET /api/v1/deposit/cabinets`
- **说明**：按寄存点与规格查询柜组/柜门可用情况。
- **鉴权**：写接口需 Bearer 令牌

## 2. 请求参数
| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| site_id | uint | 否 | 寄存点ID |
| size | string | 否 | small/medium/large |

## 3. 响应示例
```json
{"code":0,"data":{"cabinets":[{"id":1,"code":"A","size":"medium","total":20,"available":8,"status":1}]}}
```

## 4. 业务错误码
| 错误码 | 含义 |
|---|---|
| 13001 | 柜门不可用 |

## 5. 调用示例
```bash
curl "http://127.0.0.1:18080/api/v1/deposit/cabinets?site_id=1&size=medium"
```
