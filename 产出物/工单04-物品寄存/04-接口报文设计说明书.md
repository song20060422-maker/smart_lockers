# 工单04 物品寄存 — 接口报文设计说明书

> **工单编号：04｜物品寄存**　需求来源：智能快寄柜 10 份任务工单 V1.x　创建人：邹世军　出品：八维文化与产业研究院（内容由 AI 生成，仅供参考）

## 1. 通用报文约束
- 全部接口 HTTP 状态码恒定 200，业务结果由 body 中 `code` 判定（0 成功）。
- 统一响应结构（`@ticket 00-project`）：`{"code":0,"message":"ok","data":{},"request_id":"..."}`。
- 除 `/auth/login` 与回调外，业务接口均需 `Authorization` 令牌（middleware.Auth）。
- 写接口支持幂等键 `Idempotency-Key` 或 query `idempotency_key`。
- 错误码采用统一错误码表（见下），禁止自定义散落格式。

## 3. GET /api/v1/deposit/cabinets — 柜子信息查询
- 鉴权：不强制鉴权

**请求参数**
| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| site_id | uint | 否 | 寄存点ID |
| size | string | 否 | 规格筛选 |

**响应示例**
```json
{"code":0,"data":{"cabinets":[{"id":1,"size":"medium","total":20,"available":8}]}}
```

## 4. GET /api/v1/deposit/quote — 收费规则试算
- 鉴权：不强制鉴权

**请求参数**
| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| size | string | 是 | 规格 |
| hours | float64 | 是 | 时长 |
| coupon | int64 | 否 | 优惠券ID |

**响应示例**
```json
{"code":0,"data":{"amount":450,"deposit":0,"discount":100,"payable":350}}
```

**业务错误**：13002 收费规则未匹配

## 5. POST /api/v1/deposit/orders — 落单（幂等）
- 鉴权：Bearer 令牌

**请求参数**
| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| door_id | uint | 是 | 柜门ID |
| site_id | uint | 是 | 寄存点ID |
| hours | float64 | 是 | 时长 |
| coupon | int64 | 否 | 优惠券 |

**响应示例**
```json
{"code":0,"data":{"order_no":"D20260101001","amount":350,"status":1}}
```

**业务错误**：13001 柜门不可用；13002 规则未匹配；10007 重复请求；10008 并发冲突
