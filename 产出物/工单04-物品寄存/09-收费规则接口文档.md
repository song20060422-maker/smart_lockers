# 工单04 物品寄存 — 收费规则接口文档

> **工单编号：04｜物品寄存**　需求来源：智能快寄柜 10 份任务工单 V1.x　创建人：邹世军　出品：八维文化与产业研究院（内容由 AI 生成，仅供参考）

## 1. 接口概述
- **地址**：`GET /api/v1/deposit/quote`
- **说明**：按规格与时长试算费用（首段+超时封顶-优惠）。
- **鉴权**：写接口需 Bearer 令牌

## 2. 请求参数
| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| size | string | 是 | 规格 |
| hours | float64 | 是 | 时长 |
| coupon | int64 | 否 | 优惠券ID |

## 3. 响应示例
```json
{"code":0,"data":{"amount":450,"deposit":0,"discount":100,"payable":350}}
```

## 4. 业务错误码
| 错误码 | 含义 |
|---|---|
| 13002 | 收费规则未匹配 |

## 5. 调用示例
```bash
curl "http://127.0.0.1:18080/api/v1/deposit/quote?size=medium&hours=3&coupon=0"
```
