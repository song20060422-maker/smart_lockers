# 工单04 物品寄存 — 设计说明书

> **工单编号：04｜物品寄存**　需求来源：智能快寄柜 10 份任务工单 V1.x　创建人：邹世军　出品：八维文化与产业研究院（内容由 AI 生成，仅供参考）

## 1. 需求概述
实现物品寄存服务：柜子信息查询、收费规则试算、落单（鉴权+幂等+乐观锁）、支付完成与支付异常场景处理、换柜，支撑用户寄存主流程。工时约4人日。

## 2. 设计目标与约束
核心是柜门并发安全与计费准确：乐观锁抢占、幂等落单、计费规则可配置、支付状态一致。遵循全局铁律（@ticket 注释、单测≥70%、统一错误码/日志、压测报告、事务/幂等/鉴权/脱敏/审计、可配置）。

## 3. 总体架构
```
Handler(deposit.go) → Service(deposit) → Model(cabinet/door/pricing_rule/order)
  ├─ cabinets：查柜组可用柜门
  ├─ quote：计费试算
  ├─ orders：幂等落单 + 乐观锁占柜
  └─ change-cabinet：换柜
```
QueryCabinets：按 site_id/size 查可用柜门。
QuoteFee：按 size 取最高优先级规则，计算首段+超时+封顶-优惠。
CreateDeposit：幂等键去重→乐观锁占用柜门→按试算金额落 deposit_order。
ChangeCabinet：释放旧柜门、占用新柜门，更新订单 door_id（事务）。
支付完成/异常：由支付回调驱动订单状态与柜门开闭（见接口文档）。
