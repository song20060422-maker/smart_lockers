# 工单04 物品寄存 — 支付异常处理接口文档

> **工单编号：04｜物品寄存**　需求来源：智能快寄柜 10 份任务工单 V1.x　创建人：邹世军　出品：八维文化与产业研究院（内容由 AI 生成，仅供参考）

## 1. 接口概述
- **地址**：`POST /api/v1/deposit/orders（支付异常补偿）/ 换柜`
- **说明**：支付超时/失败时释放柜门或换柜，保证资源不泄漏。
- **鉴权**：写接口需 Bearer 令牌

## 2. 请求参数
| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| order_no | string | 是 | 订单号（路径） |
| new_door_id | uint | 换柜必填 | 新柜门ID |

## 3. 响应示例
```json
{"code":0,"data":{"order_no":"D...","status":3,"released":true}}
```

## 4. 业务错误码
| 错误码 | 含义 |
|---|---|
| 13003 | 寄存记录不存在 |
| 10008 | 并发冲突请重试 |

## 5. 调用示例
```bash
curl -X POST http://127.0.0.1:18080/api/v1/deposit/orders/D20260101001/change-cabinet -H "Authorization: Bearer <token>" -H "Content-Type: application/json" -d '{"new_door_id":9}'
```
