# 工单06 个人中心 — 设计说明书

> **工单编号：06｜个人中心**　需求来源：智能快寄柜 10 份任务工单 V1.x　创建人：邹世军　出品：八维文化与产业研究院（内容由 AI 生成，仅供参考）

## 1. 需求概述
实现个人中心服务：用户订单汇总、头像上传、我的服务、优惠券卡券与校验、退出登录（令牌失效），支撑用户个人信息与权益管理。工时约3人日。

## 2. 设计目标与约束
核心是用户数据隔离与令牌失效：所有接口按当前用户隔离数据、头像上传安全校验、退出登录通过 token_ver 失效历史令牌。遵循全局铁律（@ticket 注释、单测≥70%、统一错误码/日志、压测报告、鉴权/脱敏/审计、可配置）。

## 3. 总体架构
```
Handler(user.go) → Service(user) → Model(user_profile/coupon/my_service)
  ├─ 汇总：user_id → deposit_order 统计
  ├─ 头像：文件上传 + 路径入库
  ├─ 服务：按 roles 过滤
  └─ 卡券：列表 + 校验 + 退出令牌失效
```
OrderSummary：按 user_id 统计订单（复用订单数据）。
UploadAvatar：校验文件类型/大小，安全文件名，写入 avatar 字段。
MyServices：按用户角色过滤 my_service.roles。
Coupons/ValidateCoupon：券列表与有效性校验（未过期且未用）。
Logout：user_profile.token_ver 自增使旧 token 失效。

## 4. 核心流程
1. OrderSummary：按 user_id 统计订单（复用订单数据）。
2. UploadAvatar：校验文件类型/大小，安全文件名，写入 avatar 字段。
3. MyServices：按用户角色过滤 my_service.roles。
4. Coupons/ValidateCoupon：券列表与有效性校验（未过期且未用）。
5. Logout：user_profile.token_ver 自增使旧 token 失效。
