# 工单06 个人中心 — 接口报文设计说明书

> **工单编号：06｜个人中心**　需求来源：智能快寄柜 10 份任务工单 V1.x　创建人：邹世军　出品：八维文化与产业研究院（内容由 AI 生成，仅供参考）

## 1. 通用报文约束
- 全部接口 HTTP 状态码恒定 200，业务结果由 body 中 `code` 判定（0 成功）。
- 统一响应结构（`@ticket 00-project`）：`{"code":0,"message":"ok","data":{},"request_id":"..."}`。
- 除 `/auth/login` 与回调外，业务接口均需 `Authorization` 令牌（middleware.Auth）。
- 写接口支持幂等键 `Idempotency-Key` 或 query `idempotency_key`。
- 错误码采用统一错误码表（见下），禁止自定义散落格式。
## 2. 全局错误码表
| 错误码 | 含义 |
|---|---|
| 0 | 成功 |
| 10001 | 参数错误 |
| 10002 | 登录已失效 |
| 10003 | 禁止访问 |
| 10004 | 资源不存在 |
| 10005 | 系统内部错误 |
| 10006 | 操作过于频繁 |
| 10007 | 重复请求 |
| 10008 | 操作冲突，请重试 |
| 15001 | 优惠券不可用 |

## 3. GET /api/v1/user/order-summary — 用户订单汇总
- 鉴权：Bearer 令牌

**响应示例**
```json
{"code":0,"data":{"total":8,"ongoing":2,"completed":6}}
```

## 4. POST /api/v1/user/avatar — 上传头像
- 鉴权：Bearer 令牌

**请求参数**
| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| file | file | 是 | 图片文件（multipart） |

**响应示例**
```json
{"code":0,"data":{"avatar":"/uploads/avatar/xxx.png"}}
```

**业务错误**：10009 参数错误（类型/大小）

## 5. GET /api/v1/user/services — 我的服务
- 鉴权：Bearer 令牌

**响应示例**
```json
{"code":0,"data":{"services":[{"code":"deposit","name":"我要寄存","url":"/deposit"}]}}
```

## 6. GET /api/v1/user/coupons — 优惠券卡券
- 鉴权：Bearer 令牌

**请求参数**
| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| only_valid | bool | 否 | 仅有效券 |

**响应示例**
```json

```

## 7. GET /api/v1/user/coupons/:code/validate — 优惠券校验
