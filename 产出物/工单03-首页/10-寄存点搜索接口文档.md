# 工单03 首页 — 寄存点搜索接口文档

> **工单编号：03｜首页**　需求来源：智能快寄柜 10 份任务工单 V1.x　创建人：邹世军　出品：八维文化与产业研究院（内容由 AI 生成，仅供参考）

## 1. 接口概述
- **地址**：`GET /api/v1/home/sites`
- **说明**：按经纬度搜索附近寄存点，按距离升序分页返回。
- **鉴权**：读接口，不强制鉴权

## 2. 请求参数
| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| lat | float64 | 否 | 纬度 |
| lng | float64 | 否 | 经度 |
| page | int | 否 | 页码，默认1 |
| page_size | int | 否 | 每页，默认20 |

## 3. 响应示例
```json
{"code":0,"data":{"list":[{"id":2,"name":"XX寄存点","address":"金水区XX路","distance_km":0.8,"status":1}],"total":30,"page":1}}
```

## 5. 调用示例
```bash
curl "http://127.0.0.1:18080/api/v1/home/sites?lat=34.74&lng=113.62&page=1&page_size=20"
```
