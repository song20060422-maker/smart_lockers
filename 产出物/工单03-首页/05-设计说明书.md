# 工单03 首页 — 设计说明书

> **工单编号：03｜首页**　需求来源：智能快寄柜 10 份任务工单 V1.x　创建人：邹世军　出品：八维文化与产业研究院（内容由 AI 生成，仅供参考）

## 1. 需求概述
实现首页服务：定位（GPS/IP+兜底）、城市选择、附近寄存点搜索、寄存指南展示，为寄存下单提供入口。工时约3人日。

## 2. 设计目标与约束
读多写少，强调低时延与可用性；定位失败需降级兜底；寄存点搜索基于经纬度索引。遵循全局铁律（@ticket 注释、单测≥70%、统一错误码/日志、压测报告、鉴权/脱敏/审计、可配置）。

## 3. 总体架构
```
Handler(home.go) → Service(home) → Model(city/locker_site/guide)
  ├─ locate：GPS → IP → fallback_city 三级降级
  ├─ cities：关键字匹配城市
  ├─ sites：按经纬度+分页查寄存点
  └─ guide：按 version/lang 取指南
```
Locate：按 lat/lng/IP 解析城市，失败降级到 fallback_city（默认郑州）。
SearchCities：按关键字（名称/拼音/首字母）匹配，热门城市优先。
NearbySites：按经纬度计算距离排序，分页返回附近寄存点。
GetGuide：按 version/lang 取指南，默认取 is_current 版本。

## 4. 核心流程
1. Locate：按 lat/lng/IP 解析城市，失败降级到 fallback_city（默认郑州）。
2. SearchCities：按关键字（名称/拼音/首字母）匹配，热门城市优先。
3. NearbySites：按经纬度计算距离排序，分页返回附近寄存点。
4. GetGuide：按 version/lang 取指南，默认取 is_current 版本。
