# 工单03 首页 — 定位接口文档

> **工单编号：03｜首页**　需求来源：智能快寄柜 10 份任务工单 V1.x　创建人：邹世军　出品：八维文化与产业研究院（内容由 AI 生成，仅供参考）

## 1. 接口概述
- **地址**：`POST /api/v1/home/locate`
- **说明**：根据 GPS 坐标或 IP 解析当前城市；失败降级到兜底城市。
- **鉴权**：读接口，不强制鉴权

## 2. 请求参数
| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| lat | float64 | 否 | 纬度 |
| lng | float64 | 否 | 经度 |
| ip | string | 否 | 客户端IP |
| fallback_city | string | 否 | 兜底城市，默认"郑州" |

## 3. 响应示例
```json
{"code":0,"message":"ok","data":{"city":"郑州","city_id":1,"source":"gps"},"request_id":"abc"}
```

## 4. 业务错误码
| 错误码 | 含义 |
|---|---|
| 11001 | 定位失败，已降级兜底城市 |

## 5. 调用示例
```bash
curl -X POST http://127.0.0.1:18080/api/v1/home/locate -H "Content-Type: application/json" -d '{"lat":34.74,"lng":113.62,"fallback_city":"郑州"}'
```
