# 工单03 首页 — 城市选择接口文档

> **工单编号：03｜首页**　需求来源：智能快寄柜 10 份任务工单 V1.x　创建人：邹世军　出品：八维文化与产业研究院（内容由 AI 生成，仅供参考）

## 1. 接口概述
- **地址**：`GET /api/v1/home/cities`
- **说明**：按关键字（名称/拼音/首字母）检索城市，热门城市优先返回。
- **鉴权**：读接口，不强制鉴权

## 2. 请求参数
| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| keyword | string | 否 | 检索关键字 |

## 3. 响应示例
```json
{"code":0,"data":{"cities":[{"id":1,"name":"郑州","pinyin":"zhengzhou","initial":"Z","is_hot":true,"sort":1}]}}
```

## 4. 业务错误码
| 错误码 | 含义 |
|---|---|
| 11002 | 城市不存在 |

## 5. 调用示例
```bash
curl "http://127.0.0.1:18080/api/v1/home/cities?keyword=郑州"
```
