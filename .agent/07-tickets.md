# 07 · 工单 → 模块 / 表 / 接口 映射速查

> 面向具体工单开发时查本文件，业务细节以 `智能快寄柜` 目录工单 PDF 原文为准。

## 工单 01 · 消息通知（3 人日）
- 三类接收人：运营管理员、网点管理员、普通用户；四渠道：站内信/短信/邮件/回调。
- 能力：模板化 + 变量渲染、去重频控（指纹+窗口）、失败重试与升级、全链路审计、监控看板。
- 八类场景：①操作失败→管理员 ②设备异常→网点管理员 ③订单异常→用户 ④订单异常→网点管理员 ⑤取件提醒→用户 ⑥订单完成→用户 ⑦长时间未关门(>1min)→短信用户+管理员 ⑧营业前30min仍进行且预计超时→短信用户。
- 模块：event/route/template/render/dedupe/retry/audit/monitor。

## 工单 02 · 快寄员支付宝支付（3 人日）
- 四类能力：账户余额查询、余额明细查询、支付宝充值、充值记录查询。
- 约束：任意余额变动必有明细；充值与入账关系清晰；资金可追溯、可扩展（提现/退款/冻结）。
- 表：账户余额、余额明细、充值订单、充值记录；回调签名校验 + 幂等入账。

## 工单 03 · 首页（3 人日）
- 定位：GPS 优先，IP/默认回退，定位数据不持久化，短时缓存；≤200ms。
- 城市选择：按拼音首字母/中文模糊搜索、分组；JSON 词库动态更新。
- 附近寄存点：当前坐标距离排序、分页，地理索引；P95≤300ms。
- 寄存指南：版本/多语言、后台可配置，客户端按版本拉取与缓存；千级并发。

## 工单 04 · 物品寄存（3 人日）
- 柜子选择：柜子信息、可用状态、尺寸类型；P95≤200ms。
- 时间配置：起止时间、时长、超时预判、分时定价。
- 优惠+押金：优惠券叠加规则、押金规则、优惠上限。
- 收费规则：多维计费因子、优先级、版本化；收费计算 P95≤250ms。
- 支付完成：落单、状态"已占用"、支付流水、幂等。
- 异常换柜：释放占用、重算费用、重分配，事务保护。

## 工单 05 · 订单查看与取出（5.5 人日）
- 全链路"查—看—取—补—归档"；游标分页。
- 当前订单列表、历史订单列表、订单详情（寄存地点+位置）、临时开柜（限时限次+审计）、超时补交（幂等+解锁/续期）、已结束详情、进行中订单聚合。
- 约束：状态机+动作权限校验、读写分离+热点缓存精准失效、幂等键+短期锁、审计轨迹、历史归档分区。

## 工单 06 · 个人中心（2 人日）
- 五能力：用户订单查询（当前/历史，P95≤300ms）、头像上传管理（格式/大小校验，P95≤500ms）、我的服务（按角色/订阅动态配置）、优惠卡券（可用/过期、实时校验、下单幂等抵扣）、退出登录（清会话+令牌、即时失效、幂等）。
- 数据字典：用户资料表、优惠卡券表、订单表关联。

## 工单 07 · 数字人 Coze 智能体（5.5 人日）
- Coze：插件（API/语音/消息/动作）、工作流（问候/闲聊/FAQ/情绪/多轮+上下文）、知识库（标签/权重/检索）。
- Live2D：awesome-digital-human-live2d，表情/动作由回复驱动；WebSocket+RESTful。
- 消息：`{role, content, type: text|voice|command, timestamp}`。
- 指标：响应<2s、准确率≥90%、帧率≥55fps、同步误差<0.3s、断线重连100%；React+TS+Vite+Redux Toolkit（独立子模块）。

## 工单 08 · Go 后端性能调优工具链（中）
- 工具：pprof、trace、expvar、runtime/metrics、block profile、gops、pyroscope/Parca、火焰图、Prometheus/Grafana。
- 落点：订单管理模块；CPU/Heap/Block/Goroutine Profile、慢查询、锁竞争定位与优化。
- 约束：采样开销<3%；分析接口鉴权/内网限制；配置化可扩展。

## 工单 09 · Cursor/Trae 项目优化 Skills（1 人日）
- 维度：性能/瓶颈、并发与稳定性、架构与可维护、依赖与工程健康。
- 要求：IDE 内可触发、基于真实上下文、结论可解释、分级、结构统一、可复用可维护；输出含问题类型/风险等级/工程背景/优化方向。

## 工单 10 · 结合 Skills 开发设备运维智能体（5.5 人日）
- 智能体闭环：识别→计划→调用 Skills→汇总；对话触发 + 事件触发双通道。
- 能力维度：告警处置归因、状态/指标/日志/配置查询、健康巡检、变更影响评估(仅提示)、风险动作控制、输出沉淀。
- Skills ≥10 个，每个定义：名称/用途/适用场景/输入/输出/风险等级(低中高)/是否可自动执行/失败超时语义。
- 统一输出：问题类型、风险等级、工程背景、下一步动作、执行记录摘要；高风险动作无确认不得执行。
- 验收：双触发、能力覆盖、结构统一、可复用、风险确认审计、Skill 可增删升级不破坏规范。
