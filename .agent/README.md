# .agent 分规则集

本目录是智能快寄柜项目的 AI 编码规则集，配合最外层 `AGENT.MD` 使用。规则按领域拆分，AI 在进入对应开发任务前必须加载对应规则文件。

## 加载约定

1. **任何任务**：先读 `../AGENT.MD`（顶层入口），再读 `00-project.md`（全局规则）。
2. **后端开发**：追加 `01-backend.md`、`03-database.md`、`04-api.md`、`06-security.md`、`05-testing.md`。
3. **前端开发**：追加 `02-frontend.md`、`04-api.md`。
4. **具体工单**：追加 `07-tickets.md` 查对应工单的业务细节与指标。
5. **AI/Skills 类工单（09/10）或数字人（07）**：追加 `08-ai-skills.md`。
6. **代码提交/分支**：所有代码变更须遵守 `09-git-commit.md`（先创建分支再开发提交，禁止直接在主分支写代码）。

## 规则文件清单

| 文件 | 主题 | 关键内容 |
|---|---|---|
| `00-project.md` | 项目全局 | 技术栈边界、目录、命名、工单编号注释、产出物、质量铁律 |
| `01-backend.md` | 后端规范 | Gin 分层、中间件、事务、幂等、错误码、日志、缓存、pprof |
| `02-frontend.md` | 前端规范 | Vue3 目录、组件、Pinia、Axios、路由、数字人模块特例 |
| `03-database.md` | 数据库规范 | 建表字段、索引、归档分区、缓存失效、核心表清单 |
| `04-api.md` | 接口规范 | RESTful、统一报文、错误码表、分页、限流、鉴权 |
| `05-testing.md` | 测试规范 | 单测≥70%、联调、压测报告、验收标准 |
| `06-security.md` | 安全规范 | 鉴权、脱敏、幂等防重放、审计、高风险动作确认 |
| `07-tickets.md` | 工单映射 | 10 工单 → 模块/表/接口/指标速查 |
| `08-ai-skills.md` | AI 能力规范 | 工单09/10 Skills 定义、工单07 数字人联调 |
| `09-git-commit.md` | Git 提交规范 | 提交格式、6 种类型与必填规则、示例、编号校验（meegle CLI）、分支开发与合并流程 |

> 各代码子目录（`smart_lockers/`、`smart_lockers_frontend/`、`smart_lockers_admin/`、`smart_lockers_admin_frontend/`、`digital_human/`）均自带独立 `AGENT.MD` 与 `.agent/` 分规则集，按各自技术栈定制，文件命名同样采用 00–08 连续编号；进入对应子目录开发时须叠加加载本层规则。`ai-skills/` 为 Skill 文件夹，不纳入分规则体系。

## 维护约定

- 规则随项目演进持续更新；新增规则须在本表登记并指明适用工单。
- 规则内容必须来自工单原文或真实代码，禁止臆造接口、字段或指标。
- 每条规则变更需注明来源工单编号；与 `AGENT.MD` 冲突时以 `AGENT.MD` 为准。
