# 子 Skill：并发与稳定性分析（工单 09）

## 用途
识别 Go 项目中的并发使用风险与潜在稳定性问题。

## 适用场景
- goroutine 泄漏、无退出机制的常驻协程
- 共享状态未加锁 / 锁粒度不当 / 竞态
- channel 使用不当（未关闭、阻塞、无缓冲死锁）
- context 未传递或超时缺失
- defer 在循环中累积

## 分析要点
1. 每个 `go func()` 是否有明确退出条件与 context 取消。
2. 共享 map/slice/结构体的读写是否受锁保护，锁范围是否合理。
3. channel 的关闭方、缓冲、select 默认分支是否完备。
4. 网络/DB 调用是否设置超时与 context。

## 输出要求
遵循统一输出结构；数据竞争、死锁、goroutine 泄漏判为高风险；引用具体代码位置。
