# 子 Skill：依赖与工程健康度分析（工单 09）

## 用途
评估依赖使用合理性与工程结构健康状况。

## 适用场景
- go.mod 依赖冗余、版本冲突、间接依赖膨胀
- 引入重量级库完成简单功能
- 缺少 go.sum 校验、依赖未锁定版本
- 构建/测试脚本缺失或不规范

## 分析要点
1. go.mod：直接/间接依赖是否合理，是否有可替换的轻量方案。
2. 版本：是否存在已知风险版本或版本不一致。
3. 工程结构：目录规范、Makefile/脚本、测试覆盖率配置。
4. 构建健康：能否 `go build ./...`、`go vet ./...` 通过。

## 输出要求
遵循统一输出结构；依赖漏洞判为高风险，冗余/膨胀判为中低风险；引用 go.mod 具体条目。
