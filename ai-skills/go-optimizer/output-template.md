# 优化分析统一输出模板（工单 09）

每次优化分析按以下结构逐条输出，可输出多条。

```markdown
## 优化结论 #N

- **问题类型**：性能 / 并发 / 架构 / 依赖 / 工程健康
- **风险等级**：高 / 中 / 低（并说明影响程度）
- **工程背景**：<基于当前上下文的简述，引用具体文件:行号或函数>
- **优化建议**：<可执行的优化方向，非泛化口号>
- **依据**：<引用代码片段 / go.mod 条目 / 调用关系>
```

## 汇总
- 本次分析覆盖维度：<...>
- 高风险项数量：<N>（需优先处理）
- 信息缺口：<如无法判断，明确列出需补充的上下文>

## 使用价值
- 可用于 PR / MR 审查参考
- 可沉淀为项目优化记录
- 可作为团队工程质量评估依据
