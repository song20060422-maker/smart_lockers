# 运维分析统一输出结构（工单 10）

每次运维分析输出按以下结构，必须包含全部字段。

```markdown
## 运维分析结论

- **问题类型**：告警 / 性能 / 网络 / 存储 / 服务 / 配置 / 变更影响
- **风险等级**：低 / 中 / 高（并标注影响程度）
- **运维背景**：<基于上下文的简述：设备、时间窗口、指标/告警现象、相关服务>
- **下一步动作**：<可执行建议 / 排查步骤 / 需要补充的信息>
- **执行记录摘要**：<调用了哪些 Skills、各自结论要点>

### 高风险动作（如有）
- 动作：<重启/隔离/限流/回滚>
- 状态：**待确认**（无确认不得执行）
- 确认记录：<见 audit/ 审计日志，含操作人/时间/依据>

### 信息缺口（如有）
- <明确列出缺失的上下文与补充建议，不臆断>
```

## 字段说明
- 问题类型 / 风险等级：用于统计与分级检索。
- 运维背景、依据：保证结论可解释、可复盘。
- 执行记录摘要：体现 Skills 编排过程，便于同类事件复用。
- 高风险动作：与确认审计机制联动，留痕可追溯。
