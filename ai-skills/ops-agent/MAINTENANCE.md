# 维护与演进（工单 10）

## 新增 Skill
在 `skills/` 下按统一规格新增文件，必须包含：名称、用途、适用场景、输入字段、输出字段、风险等级、是否自动执行、失败/超时语义；并在 `SKILLS.md` 对应类别登记。

## 升级 / 下线
- 升级：直接修改对应 Skill 文件，保持字段完整与统一输出结构不变。
- 下线：从 `SKILLS.md` 移除并标注归档，不删除历史审计关联。
- 风险动作类新增：必须沿用“需确认 + 审计”占位模式，自动执行=否。

## 不破坏规范
- 统一输出结构（output-schema.md）字段不得删减。
- 双触发配置（triggers/）与确认审计（audit/）为全局约束，任何 Skill 均须遵循。
- 风险分级语义保持一致（低可直接输出，高必须确认）。

## 多人复用与资产化
- 分析结论可沉淀为运维知识记录（同类问题复用）。
- 输出结构统一、可统计/可检索，可作为运维质量评估依据。
