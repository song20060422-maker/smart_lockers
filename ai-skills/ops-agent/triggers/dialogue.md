# 对话触发（工单 10）

## 触发方式
运维人员通过自然语言对话输入触发运维智能体任务，例如：
- “检查设备 A CPU 高的原因并给建议”
- “设备 0203445006 离线了，帮我归因并给处理建议”
- “对展示区设备做一次健康检查并生成报告”

## 解析要求（识别阶段）
智能体从对话中提取以下上下文，缺失则追问或声明缺口：
- 设备标识（device_id / 区域 / 类型）
- 现象/诉求（告警、指标异常、巡检、变更）
- 时间窗口
- 相关服务 / 历史事件工单（如有）

## 编排与输出
按 [AGENT.md](../AGENT.md) 闭环选择 Skills；输出遵循 [output-schema.md](../output-schema.md)；
高风险动作进入 [确认审计流程](../audit/confirmation-and-audit.md)。
